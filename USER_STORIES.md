# ApronLink — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Traveler experience PM

- As a PX PM, I want beacon paths from check-in to gate, so visitors do not miss flights in unfamiliar terminals.
- As a PX PM, I want safety-mode to mute offers, so commerce never overrides security messaging.

### Concession partner

- As a partner, I want stage-targeted offers with attribution, so I pay for real footfall not spray ads.

### Airport ops

- As ops, I want disruption alerts on the same channel as wayfinding, so passengers get one source of truth.
- As ops, I want configurable Wi-Fi grant windows, so event campaigns do not become permanent free-ride.

### Commercial lead

- As commercial, I want time-to-launch metrics for new services, so we prove post-event agility.

### Exception

- As a traveler support agent, I want to revoke location history on request, so privacy complaints are actionable.

### Admin

- As an admin, I want partner API scopes limited to their venues, so competitors cannot see each other’s offers.
